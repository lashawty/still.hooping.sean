## AI 做什麼、不做什麼

| | |
|---|---|
| AI 做 | 轉錄每支影片的口白和字幕；從 IG 洞察報告抓瀏覽、觸及、互動、儲存、追蹤；算互動率、儲存率、追蹤率；每支寫三個重點；每週更新計分板 |
| AI 不做 | 想題目、寫腳本、寫 caption、回留言。這些是我的聲音，不外包 |

怎麼做：Chrome 開 IG 網頁版讀洞察報告，本機 whisper.cpp 轉口白，產出放 `reports/`。

## 規則

1. AI 的輸出是給我看的報告，繁體中文、台灣用語。
2. 數字要能回溯：每個比率旁邊都要有原始數，網頁版沒給的欄位（分享、完播率）直接寫沒有，不估。
3. plugin 和 skill 裝在這個 repo，不裝到 user level。清單在 `.claude/settings.json`。
